# void-run

**VOIDRUN** is an arcade-style browser game about dodging glitches and progressing through levels. The page includes on-screen instructions and score and level displays.

## Play locally

Open `index.html` in a modern browser, or run a local server from the project folder:

```sh
python -m http.server 8000
```

Then visit http://localhost:8000. Use the on-screen instructions to get started.
